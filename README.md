# BeeSkilled — Machine Learning & AI

Weekly assignments and mini projects for the BeeSkilled Machine Learning & AI course, by **Raman** (B.E. CSE — AI & ML, Chandigarh University).

## Week 1 — ML Fundamentals + Data Preprocessing
Focus: Basics of ML, Data Cleaning, Feature Engineering

- **Assignment 1:** Load a dataset using Pandas and summarize basic stats (`.info()`, `.describe()`)
- **Assignment 2:** Handle missing data using mean/median imputation
- **Assignment 3:** Encode categorical variables using LabelEncoder & OneHotEncoder
- **Mini Project 1:** Titanic Survival Prediction — Data Cleaning Project (clean missing data, encode Sex & Embarked, age distribution chart, cleaned dataset as CSV)
- **Practice Set:** Load CSV & print rows, train/test split, Linear Regression, house price prediction

Files in `Week-1/`:
- `Week1_ML_AI_Assignment_Raman.ipynb` — complete executed notebook with outputs
- `titanic_cleaned.csv` — cleaned Titanic dataset (891 rows) produced by the mini project

## Week 2 — Supervised Learning (Regression & Classification)
Focus: Model building, training, accuracy testing

- **Assignment 1:** Linear Regression on a housing dataset (predict price) — R² 0.79, RMSE $39,711
- **Assignment 2:** Logistic Regression on the Titanic dataset for survival prediction — 81.01% accuracy
- **Mini Project 2:** House Price Prediction Model on the Kaggle House Prices dataset — Linear Regression on all 37 numeric features, R² 0.82, RMSE $36,880, predicted vs actual plot
- **Practice Set:** Logistic Regression + confusion matrix (81.01%), Decision Tree vs KNN comparison (Logistic Regression best at 81.01%), Decision Tree `max_depth` tuning (best test accuracy 79.89% at depth 3; unlimited tree overfits — 97.89% train vs 78.77% test)
